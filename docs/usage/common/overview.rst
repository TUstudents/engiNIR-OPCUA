===============
Common Overview
===============

OPC-UA is built around the concept of namespaces and nodes. This concept is
present in the server and the client and therefore much of the code is shared
by both. In this section we take a look at the shared part of the library.

The shared code lives in the :mod:`enginir_opcua.common`, :mod:`enginir_opcua.ua`
and :mod:`enginir_opcua.crypto` packages and the most important classes and methods
from these packages will be discussed in the following sections.


enginir_opcua.common package
============================

The :mod:`enginir_opcua.common` package is provides the core functionality of the library.
Several important parts life in this subpackage, for example the :class:`~enginir_opcua.common.node.Node`
class and the :mod:`~enginir_opcua.common.subscription` module. You can find usage examples
of these classes and functionalities in the following sections.


enginir_opcua.ua package
========================

The :mod:`enginir_opcua.ua` package contains mostly autogenerated code which reflects the standard
objects, attributes and status codes provided by the OPC-UA standard.

enginir_opcua.crypto package
============================

Code related to permissions, security and encryption is located in the :mod:`enginir_opcua.crypto`
package.
